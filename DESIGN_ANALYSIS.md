# Design Analysis — Task 4

The source document defines two main interface groups:

## Manager / Administrator
1. Manager Login
2. Reset Your Password
3. Verify Your Request
4. Create New Password
5. Manager Dashboard
6. Teachers
7. Add Teacher
8. Delete Teacher
9. Edit Teacher

## Teacher
10. Teacher Home
11. Generate Summary
12. Upload Reference
13. Previous Summaries
14. References

The implementation preserves the required content and relationships while improving spacing, typography, cards, forms, tables, badges, responsive behavior and subtle animations.

The original specification explicitly requires frontend-only behavior with dummy data, functional navigation, validation, search, add/edit/delete operations and a README.
